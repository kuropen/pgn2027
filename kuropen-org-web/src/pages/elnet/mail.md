# eternie-labs.net メールサーバーについてのお知らせ
当ドメインで使用されているメールアドレスは、2011年ごろに情報漏洩による大規模な不正利用がなされており、正規でないサーバーから大量のスパムメールが送信されている可能性があります。
当ドメイン運用者ではDMARCレコードの設定など可能な限り防御に努めていますが、万一不審な内容のメールが届いた場合は、無視・破棄いただきますよう、よろしくお願い致します。

また、2024年2月16日ごろより、MisskeyおよびMastodonインスタンスを対象とした大規模な攻撃の中で、Kuropenが[自営のMisskeyインスタンス（MICROPEN）](/micropen/)の問い合わせ先として当ドメインのメールアドレスを指定していたため、 それに関連する不正利用も確認されております。企業様のお問い合わせフォームにおいて、当ドメインのメールアドレスが利用された不審な投稿がありました場合は、不正利用の可能性を視野に入れてのご対応のほど、よろしくお願い致します。

不審なメールの着信などでお困りの方は、[お問い合わせフォーム](https://kuropen.org/contact/)宛にご連絡ください。
